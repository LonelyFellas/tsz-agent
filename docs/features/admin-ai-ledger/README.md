# 超管 AI 账本

本次覆盖 Agent 的模型调用记录，沿用本任务缓存与耗时统计。只读，不调用付费模型，不修改词库缓存。

## 依赖与方案

- 已实现并复用：Agent 调用账本/逐次统计；tsz-rust 的 Agent 服务配置与管理员身份校验；admin 超管路由门禁与 Ant Design。
- 新增：Agent `GET /v1/model-calls` 分页读取及同筛选条件的汇总；tsz-rust `GET /api/v1/admin/ai-ledger` 鉴权代理；admin `/ai-ledger` 页面。
- 两端查询参数为 `page`（1 基）、`page_size`（1–100）、可选 `run_id`。默认最新调用在前，同时间按调用 ID 排序。汇总覆盖所有符合条件的调用，不限当前页。
- 返回调用 ID、任务 ID、委托 ID、模型、预留时间、已知输入/输出 token、费用及逐次缓存/耗时观测。费用没有权威回执时为 `null`；缺失观测不伪造零值，也不当作成功。
- 业务后端复用 `VOCABULARY_AGENT_*` 服务连接；浏览器只访问业务后端，服务密钥不下发。服务未配置、上游不可达或契约不符返回脱敏 503，不把错误伪装成空账本。
- 权限采用后端当前有效的 `super_admin` 身份，不能通过词库权限或权限标签委派。前端隐藏菜单并在业务查询挂载前拦截直链/撤权；后端路由策略和 handler 都检查身份。

## 验收

1. 超管可分页查看账本、按任务 ID 筛选，汇总按已知 token 加权；零值与未知值展示有区别。
2. 普通管理员（包括持有词库权限者）看不到入口，直链不加载数据，直接 API 请求返回 403；未登录及过期/撤销会话不能读取。
3. 上游超时、旧版无接口、异常响应清晰显示不可用，响应和日志不暴露服务密钥或原始异常。
4. Agent 测试使用独立本地 `tsz_agent_test`；Rust 权限测试使用本任务隔离 PostgreSQL/Redis；浏览器验证真实本地前端→Rust→Agent→账本链路，模型回执为明确标识的测试 fixture。

## 设计收敛

按用户指定的 `huashu-design` 评审方法，基于现有 Ant Design 主题、品牌蓝和真实账本页面迭代。此页的核心是「先看整体效率，再定位单次调用」，因此采用紧凑四栏概览与明细表的上下结构。

- 概览合为一条数据带，用输入量、缓存命中和耗时形成稳定扫读顺序；回执覆盖量保留为次级说明。
- 筛选与调用明细同组，完整任务 ID 输入框和查询/重置按钮保持连续；长篇统计口径改为可点击说明。
- 模型与阶段合列，时间分两行；数值右对齐并使用等宽数字。缓存率以数值和实际比例条表达，零命中与未知保持区别。
- 表格最小宽度从 1100 缩到 800，常用桌面视口可以同时看到耗时与费用。详情按屏幕宽度使用一列或两列，窄屏概览变为两栏。
- 沿用服务端权限和数据查询语义；没有新增模型调用、计费推算或词库缓存。

设计复核：信息层级、字段对齐与未知状态已在内置浏览器验证，筛选和统计口径展开正常；49 项相关页面/权限测试通过。截图中的调用数据均来自隔离 fixture，不是现网指标。
