# 模型输入精简与前缀复用

## 实现

本次仅修改 Agent 的模型输入与评测适配，不改变 Rust 来源契约、Agent API、数据库结构、调用预算或费用口径。

- `models/inputs.py` 生成独立模型视图。保留拼写、词性、等级、释义、其他释义、有效拼写变体和英美档位；完整来源、发布版本、指纹、任务和审核事件身份继续留在原任务数据中，不发送给模型。
- 候选按原召回顺序分配 `c01` 等短编号，只在本次 `generate()` 调用内有效。模型返回三个不同的当前编号后，先还原为原始 `candidate_ref`，再交给既有选择、来源与授权检查；未知、重复编号或返回原始引用均拒绝，已发生用量仍被记录。
- 补查后的生成独立建立映射；SDK 结构修复重试沿用当前映射。持久化的候选、提案与最终结果保持原始权威引用，断点中不写短编号。
- 人工案例保留审核决定、原因、评论、完整语义和具体经验；现有检索、撤销、乱序与来源复核仍在精简前执行。案例不扩大候选范围，不把模型总结变成人工确认的规则。
- 固定指令之后，正文依次是精简候选池、目标上下文和当前有效人工案例，使用紧凑 JSON。任务 ID 不参与模型正文，不重排候选以追求命中，不增加全库缓存或主动付费预热。
- 复查仅投影四个选项的模型字段，保留 A/B/C/D、原题干、预期答案和建议题干的区分，不带入生成者的自评。评测入口使用相同投影路径。

## 版本与缓存

复用逐词条 `publication_id` 和现有严格来源匹配，不引入全库版本号。含义变化会更新发送的语义；仅来源版本变化、语义相同的请求可能复用相同计算前缀，但当前调用的短编号仍还原到当前发布版本的原始引用。模型缓存不能使旧来源、旧授权或已撤销案例恢复有效。

DeepSeek 的自动缓存只处理匹配前缀；需要继续发送完整上下文，不保证缓存命中率。依据：[官方缓存说明](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)。验收应同时查看实际输入、未命中 token、重试次数和每道合格草稿成本，不能只追求命中率。

提示词版本更新为 `mcq_zh_en_v4`。当前工作流会在调用模型前拒绝其他版本的非空断点。发布前须暂停提交新命题、排空旧版本在途和待重试任务，再切换 worker；回退同样须先排空 v4 任务。不要修改断点版本号强行恢复。无需数据库迁移，历史终态结果保持原引用。

## 离线测量

以分支基点 `1463bdfa947ec0d650d28e8b89c178808caa9433` 的旧适配器和新版适配器，通过同一锁定 SDK、同一固定指令及输出 schema，用 `httpx.MockTransport` 捕获完整请求。40 个候选使用合成 UUID/指纹，含并列释义、其他词义和拼写信息；另测 4 条合成人工案例。未读取实际业务任务正文、未请求供应商。

| 样本与阶段 | 旧请求字节 | 新请求字节 | 旧近似消息 token | 新近似消息 token | 近似降幅 |
|---|---:|---:|---:|---:|---:|
| 40 候选，生成 | 39,841 | 15,771 | 15,770 | 4,069 | 74.2% |
| 40 候选＋4 案例，生成 | 56,487 | 21,266 | 22,499 | 5,504 | 75.5% |
| 四选项复查 | 5,483 | 3,021 | 1,940 | 769 | 60.4% |

字节数覆盖 JSON 请求；近似 token 覆盖包含固定指令、输出格式说明的消息文本，使用本地通用分词器，不是 DeepSeek 官方分词或实际回执。两版本固定指令相同，用于隔离输入投影的影响；表中不包含缓存收益。数值四舍五入可能随固定提示词的小幅修改变化。

首轮真实对比目标为同类样本的生成输入 token 减少至少 50%，并复核来源边界、题目质量、重试和合格草稿成本。真实模型质量与缓存命中须另行验证，离线缩减不能宣称为实际费用降幅。

## 回归范围
