# 模型费用预估与首页周期汇总

用户已确认按实际 token 和官方计价规则展示「预估模型费用」，与供应商实际账单区分；缺失回执继续未知。仅涵盖本 Agent 模型调用，不代表整个 DeepSeek 账户、语音或其他服务的消费。

## 事实与计价依据（2026-10-28 核实）

- [DeepSeek 调用回执](https://api-docs.deepseek.com/api/create-chat-completion/) 提供输入、输出及命中/未命中 token，不提供逐笔扣费。
- [余额接口](https://api-docs.deepseek.com/api/get-user-balance/) 只提供当前余额，不能还原日/周/月账单。SDK 的 cost 可能来自第三方价格估算，不视为实际账单。
- [官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：deepseek-flash 每百万 token，空闲命中/未命中/输出为 0.02/1/4 元，高峰为 0.04/2/8 元。
- 高峰为北京时间周一至周五 09:00–12:00、14:00–18:00，排除中国节假日；周末即使是调休工作日也按官方「周末为空闲」口径处理。[2026 年政府公布放假安排](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html) 已纳入版本化日历。
- 当前计价依据覆盖 2026-10-28 至 2027-01-01（不含）。到期前必须核实新价格与下一年日历再更新；超出覆盖期的新调用不估算，继续记录用量与未知费用，不影响生成。

## 实现与兼容

1. Agent 预留调用时保存模型、人民币单价、价格版本、高峰/空闲及时间快照。完成用量和缓存回执后，用 Decimal 计算并保存 Numeric(24,12) 预估金额；后续价格更新不会重算旧调用。
2. 费用按调用预留/发起时间归属周期，高峰与空闲也使用该时间；供应商实际计费时点、折扣或其他收费可能导致账单差异，所以始终标为预估。
3. 重试分别记账；重复回执不重复累计，取消/租约移交不丢掉迟到回执，乱序的 token/缓存回执都能收敛。费用未知不释放未知消费预算。
4. 旧调用没有价格快照时不按今天价格回填。空周期返回已确认的 0；有调用但无可计价记录返回 null；部分未知时返回已知部分金额和未知数量，UI 明示「仅含已知部分」。
5. 新增 Agent `/v1/model-costs`、`/v1/model-costs/overview` 和 Rust `/api/v1/admin/ai-ledger/costs`、`/api/v1/admin/ai-ledger/cost-overview`。既有账本、任务响应及其 cost 字段保持原有语义；费用新契约不向旧严格客户端添加字段。
6. 首页独立费用区块显示累计/今日/本周/本月。周期按北京时间自然日、周一和自然月起点到同一个 generated_at，开始含、结束不含。服务端独立超管鉴权，普通管理员组件不挂载查询，撤权后卸载内容。
7. 账本切换到费用投影，按 call_id 关联逐次价格与预估金额，保留面包屑；无需浏览器接触供应商密钥。
