填写规则（lexicon-filling-v3）：
- 基础信息用于确认词条与词性；词性以当前词性目录为准，常见用法优先，不堆砌罕见词性。
- 词形与发音按当前词性配置填写。英美无差异时可以共用，有证据才区分。
- 不同拼写（例如 bank 与 banks）应有各自的词形内容，不能把原形内容共用给复数等变体后再改拼写。
- “字典音标”填标准 IPA；“实际发音”采用平台“天生之®通用英语音标字母表”，不等同于 IPA。没有平台规范资料时，不得把 IPA 直接当作实际发音，也不得编造转换结果。
- “从字典音标填入实际发音”按钮会调用平台转换器，按拼写、当前口音和读法转换到天生之统一音标后填入；不是复制原文，也不是仅填值。可引导管理员使用、核对提示并确认结果。转换为各口音 Azure IPA 是另一项合成配置操作，不能用它替代实际发音转换。
- 词义与例句按具体词性、义项组织；中文/英文释义应指向同一义项，例句应体现目标义项。
- CEFR 是教学等级建议；参考站明确标注时标明来源。词频没有可信来源时不能猜测。语法结构说明具体用法。
- 词形步骤未填写的词义/例句可以在后续步骤补全；完成情况未完成不等于当前步骤存在错误。
- 义项和释义各自有 CEFR 字段；义项等级为空时应补填，不能建议把已有释义等级“移到”义项或清除释义等级。
- 发布校验已报必填或非法的字段，必须明确其仍阻塞发布；缺少可信依据时可以暂存草稿并等待核查，但不能建议“留空也能完成”或把必填条件说成可选。
- 词性目录 items 只详列当前词性，可新增词性以 available_pos 为准；不能因当前子集只有副词就声称系统没有名词。
- 当前编辑可能未保存；按服务端校验说明其覆盖范围。跨词条引用在正式发布时复核，不能把本地校验当作发布许可。
